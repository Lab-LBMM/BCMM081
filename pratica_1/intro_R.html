Vetores e matrizes

Propriedades de vetores

  • Unidimensional (1D)
  • Células com endereço (índice) de 0 a N
  • Comprimento definido e pode ser recuperado com length()
  • Itens devem ser do mesmo tipo
  • Subconjuntos de vetores são acessados com []

Lists

Atenção: Objetos do tipo list podem armazenar dados de tipos diferentes sem convertê-los.

Propriedades de matrizes

  • Bidimensional (2D)
  • Endereço com índices
    • Linhas têm índices antes de vírgula
    • Colunas têm índices depois de vírgula
  • Subconjuntos de vetores são acessados com [linha, coluna]

Arrays

Termo usado para qualquer objetivo com N dimensões

  • Célula única (0)
  • Vetor (1D)
  • Matriz (2D)
  • Arrays com mais de 2 dimensões

Trabalhando com arquivos

Nossos dados científicos, especialmente de ômicas, geralmente estão representados em arquivos grandes armazenados em nossos computadores.

Arquivo comumente usados

  • Microsoft Excel (.xlsx)
  • Arquivos de texto facilmente exportados do Excel
    • Comma Separated Values (.csv)
    • Tab Separated Values (.tsv)
  • Importamos no R com a função read.csv()

Onde estamos ?

Funções básicas para se localizar no R:

  • getwd(): verificar o caminho até o local de trabalho
  • setwd(): alterar o caminho até o local de trabalho

Objeto tipo data.frame

Como representamos dados tabulares no R?

  • Tem duas dimensões, como uma matriz
  • Possui informações adicionais de indexação de linhas e colunas
  • Existem várias funções para trabalhar com data.frame

Funções para recuperar subconjunto

  • Sintaxe com [] e índices ou nomes de colunas
  • subset()

Operações para cálculo de estatísticas de grupos

  • aggregate()
  • tapply() - gera um array
  • lapply() - list
  • sapply() - vector (vetor 1D)

Salvando arquivos no computador

  • write.csv()

Controle de fluxo e estruturas condicionais

  • Operador que avalia o valor FALSE/TRUE: if() {}
  • Operação para estabelecer uma alternativa, caso FALSE: if() {} else() {}
  • if aninhado: if() {} else { if() {} else() {} }
  • Versão compacta do if-else: ifelse()
  • Realiza uma operação até que certa condição seja estabelecida: for() {}
  • Laço aninhado: for() { for() {} }
  • Laço que se repete enquanto a condição for verdadeira: while() {}

Pacotes em R

Conjuntos de funções agrupadas juntas em um único “lugar”

Exemplo: Tidyverse

Conjunto de pacotes que compartilham representações de dados, trabalhando harmonicamente entre si.

  • ggplot2 (visualização de dados)
  • dplyr (manipulação de dados)
  • Outros: tidyr, readr, purrr, tibble, stringr, forcats e lubridate

Tidyverse torna simples a instalação de todos esses pacotes de uma vez.

Gráficos em R

A biblioteca mais popular para gráficos em R é o ggplot2, incluída no Tidyverse [ggplot2) e desenvolvida pelo mesmo grupo que criou o R Studio

Por que gerar gŕaficos na linha de comando…

Alguns motivos

  • A prática leva ao aumento da velocidade
  • Uso de código dá maior controle sobre os aspectos do gráfico
  • Com o código e os dados disponíveis, a visualização se torna reprodutível

Conceitos importantes sobre gráficos

Raster vs. Vetor

  • Formatos de arquivo
    • Raster - cor e intensidade de pixels (.jpeg/.jpg, .png, .tiff, .bmp)
    • Vetor - formas (.svg, .pdf, .eps)
  • Dê preferência para vetores, evitando imagens “pixeladas”
  • Exceções: fotos, dados em grades, arquivo gigantes (c/ milhões/bilhões de pontos)

Conceitos importantes sobre gráficos

Resolução vs. dimensão

  • Dimensão de pixel combina dois aspectos
    • Tamanho
    • Resolução (megapixel, dpi - “dots per inch”)

Conceitos importantes sobre gráficos

Acessibilidade

  • Vieses culturais (azul e vermelho, frio e calor)
  • Visualização por indivíduos com algum tipo de daltonismo
    • Maximizar diferenças em espectro e intensidade
  • Impressão em preto e branco

Alguns gráficos básicos

  • Variáveis categóricas ou contínuas
  • Composição: ggplot(), geralmente incluindo a função aes() e o parâmetro data=
  • geom_<name> define o tipo de saída / gráfico
