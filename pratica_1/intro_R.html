Tipos de dados

Programação orientada a objetos

Variáveis

  • São objetos que podem ter seus valores alterados
  • Usamos = ou <- para atribuir ou alterar valores associados a variáveis em R

Vetores e matrizes

Propriedades de vetores

  • Unidimensional (1D)
  • Células com endereço (índice) de 0 a N
  • Comprimento definido e pode ser recuperado com length()
  • Itens devem ser do mesmo tipo
  • Subconjuntos de vetores são acessados com []

Lists

Atenção: Objetos do tipo list podem armazenar dados de tipos diferentes sem convertê-los.

Propriedades de matrizes

  • Bidimensional (2D)
  • Endereço com índices
    • Linhas têm índices antes de vírgula
    • Colunas têm índices depois de vírgula
  • Subconjuntos de vetores são acessados com [linha, coluna]

Nomes que o R aceita

Funciona

abundancia

Não funciona

2ninhos      # começa com número
n ninhos     # tem espaço

R diferencia maiúsculas de minúsculas: Dados e dados são dois objetos distintos.

Tudo é um vetor

comprimento <- c(8.2, 9.1, 7.4, 10.3, 8.8)
comprimento
#> [1]  8.2  9.1  7.4 10.3  8.8
mean(comprimento)
#> [1] 8.76
length(comprimento)
#> [1] 5

Operações são vetorizadas — sem for:

comprimento * 2
#> [1] 16.4 18.2 14.8 20.6 17.6

Os quatro tipos que você vai usar

c(8.2, 9.1)                     # numeric  — medidas
#> [1] 8.2 9.1
c("Atta", "Acromyrmex")         # character — nomes, IDs
#> [1] "Atta"       "Acromyrmex"
c(TRUE, FALSE)                  # logical  — resultado de testes
#> [1]  TRUE FALSE
factor(c("mata", "borda"))      # factor   — categorias com níveis
#> [1] mata  borda
#> Levels: borda mata

Um vetor guarda um tipo só. Misture e o R converte tudo em texto, sem avisar:

c(1, 2, "três")
#> [1] "1"    "2"    "três"

Data frames

A tabela

coletas <- data.frame(
  ninho     = c("N01", "N02", "N03", "N04"),
  habitat   = c("mata", "borda", "mata", "borda"),
  operarias = c(120, 85, 143, 61),
  massa_g   = c(4.2, 3.1, 5.0, 2.4)
)
coletas
#>   ninho habitat operarias massa_g
#> 1   N01    mata       120     4.2
#> 2   N02   borda        85     3.1
#> 3   N03    mata       143     5.0
#> 4   N04   borda        61     2.4

Olhando antes de analisar

str(coletas)      # estrutura
head(coletas)     # primeiras linhas
summary(coletas)  # resumo por coluna
nrow(coletas)     # nº de linhas
names(coletas)    # nomes das colunas
str(coletas)
#> 'data.frame':    4 obs. of  4 variables:
#>  $ ninho    : chr  "N01" "N02" "N03" "N04"
#>  $ habitat  : chr  "mata" "borda" "mata" "borda"
#>  $ operarias: num  120 85 143 61
#>  $ massa_g  : num  4.2 3.1 5 2.4

Recortando a tabela

coletas$operarias
#> [1] 120  85 143  61
coletas[coletas$habitat == "mata", ]
#>   ninho habitat operarias massa_g
#> 1   N01    mata       120     4.2
#> 3   N03    mata       143     5.0
coletas[1:2, c("ninho", "massa_g")]
#>   ninho massa_g
#> 1   N01     4.2
#> 2   N02     3.1

Erros que todo mundo comete

Error: object 'coletass' not found → nome digitado errado ou objeto ainda não criado.

Error in ... could not find function "ggplot" → falta library(ggplot2).

O + no console → você deixou um parêntese ou aspas abertos. Esc cancela.
